🔍 Hybrid Retrieval Engine

// TF‑IDF + semantic embeddings
class HybridRetrievalEngine {
  retrieve(query, k = 5) {
    // Expand query with synonyms
    const expanded = this.expandQuery(query);
    // BM25 + cosine similarity
    const scores = this.chunks.map(c => ({
      score: this.bm25Score(expanded, c.text) * (1 - semanticWeight) +
           this.cosine(this.embed(expanded), c.embedding) * semanticWeight
    }));
    return scores.sort((a,b) => b.score - a.score).slice(0, k);
  }
}

Combines lexical (BM25) and semantic (cosine) scoring with a tunable weight. Query expansion adds synonyms automatically.
