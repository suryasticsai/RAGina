EXHIBITS A–F

What's actually inside the file.

Six capabilities, all in one ~25KB script. No build step, no server changes required. Just a <script> tag.

CORE
📚

Document retrieval

Client-side TF-IDF search index. Load docs via folder, JSON, or URL — RAGina chunks, scores, and retrieves passages entirely in the browser.

NEW IN T1
🔧

Tool calling

Register any JS function as a tool. When docs can't answer, RAGina asks for a tool, runs it, reads the result, and only then replies — a true ReAct loop.

NEW IN T1
👻

Headless mode

RAGina.query() returns an answer with zero UI. Built for embedding inside your own interface — phone apps, bots, consoles.

CORE
💬

Chat widget

Optional floating bubble + panel. Shows live "🔧 using toolName…" tags while a tool call is in flight, so tool use is visible, not silent.

NEW IN T1
🌐

Web search tool

Built-in Wikipedia + DuckDuckGo fallback. No API key required — the agent can look up anything documents don't cover.

NEW IN T1
📅

Calendar & email

Pre-filled Google Calendar events and mailto: drafts. The agent takes action in the real world, not just inside the chat.

HOW THE BRAIN WORKS

The ReAct loop — visualised.

Your backend is a plain prompt-in / text-out endpoint. So the agentic reasoning happens entirely on the client — up to 4 steps per question, then a final answer.

①
STEP 01

Ask

Question + tool list + recent context go into a single prompt.

②
STEP 02

Decide

Model replies TOOL_CALL or ANSWER — nothing in between.

③
STEP 03

Act

Your JS handler runs. Result is recorded into the tool log.

④
STEP 04

Repeat

Up to 4 iterations, then a final ANSWER is produced.

DEPOSITION

Three lines to get started.

A few more to give it hands.

quick-start.html
<!-- 1. include the script -->
<script src="https://cdn.jsdelivr.net/gh/suryasticsai/RAGina@main/ragina-t1.js"></script>

<script>
  // 2. load what it should know
  RAGina.loadData({
    "faq.html": { bodyText: "Refunds take 5–7 business days..." }
  });

  // 3. that's it — the chat bubble is live
</script>
register-a-tool.js
RAGina.registerTool('lookupOrder', {
  description: 'Look up an order by its ID',
  parameters: { orderId: 'string, e.g. "A1234"' },
  handler: async ({ orderId }) => {
    const r = await fetch('/api/orders/' + orderId);
    return r.ok ? await r.json() : 'Order not found.';
  }
});
headless-query.js
// No widget — use RAGina's brain inside your own UI
const { answer, steps } = await RAGina.query('Where is order A1234?');
console.log(answer);   // "Order A1234 shipped yesterday, arriving Thursday."
console.log(steps);    // full trace — which tool ran, with what args

WHAT'S NEXT

From T1 to T3 — the roadmap.

Each tier adds a layer of autonomy. T1 is live. T2 and T3 are in progress.

● LIVE · T1

Tier 1 — Agentic Core

Document retrieval + tool-calling via ReAct loop. The foundation.

  • Client-side TF-IDF retrieval
  • registerTool() / unregisterTool() API
  • Headless query() mode
  • Built-in: webSearch, scheduleEvent, draftEmail, getTime, calculate, openUrl
  • Chat widget with live tool-use tags
◆ SOON · T2

Tier 2 — Memory & Multi-tool

Long-term memory and chained tool use across a conversation.

  • Long-term memory (localStorage + retrieval)
  • Multi-step tool chains
  • Sub-agent router (researcher / coder / writer)
  • Voice-activated wake word
  • Per-user persistent profiles
◇ LATER · T3

Tier 3 — Autonomy

RAGina as an embedded agent that can act on your behalf.

  • Vision understanding (screenshots, images)
  • Browser automation (form fill, clicks)
  • Self-correction loop (quality scoring)
  • Proactive suggestions from page context
  • PSTN/SIP dial-in for phone agents
