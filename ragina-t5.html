Drop the file next to your HTML, or load it from jsDelivr. T5 is fully standalone — it does not need T4.

index.html 
<!-- Load T5 (standalone, ~1 file) -->
<script src="https://cdn.jsdelivr.net/gh/suryasticsai/RAGina@main/ragina-t5.js"></script>

<script>
  (async () => {
    await R5.init({ voiceId: 'rachel' });
    R5.registerAll();
    console.log(R5.listTools()); // 21 tools
  })();
</script>
Talk to her 
// Index a document (persists in IndexedDB)
await R5.loadData({
  'handbook.txt': 'Vacation policy: 20 days per year...'
});

// Ask — RAG happens automatically before the LLM
const r = await R5.query('How many vacation days do I get?');
console.log(r.answer);

// Or hand her a multi-step goal
const m = await R5.planAndExecute(
  'Search my notes for Q3 revenue and draft a summary email'
);
console.log(m.plan, m.answer);
01

Load the file

One <script> tag from jsDelivr, or host ragina-t5.js yourself. It works on any static page — GitHub Pages, Netlify, a single HTML file.

02

Initialise once

R5.init() detects the device tier, restores the RAG index from IndexedDB, and wires the audio session. R5.registerAll() adds the 21 tools.

03

Feed her knowledge

R5.loadData(), R5.loadFile() or R5.loadFolder(). She chunks, embeds and indexes locally. No upload, no server.

04

Ask, speak, act

Every R5.query() auto-retrieves the top 5 chunks. Voice, music, forms and guides are all available as tools to the agent.

✓

Optional: pair with T4

If ragina-t4.js is also loaded, T5's tools automatically register into T4's engine too. No conflict — T4 just gets 16 extra tools.
